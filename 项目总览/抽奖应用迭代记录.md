# 抽奖应用迭代记录

> 抽奖 Web 应用迭代台账（扭蛋机/盲盒抽奖系统）— 安全产品二部&三部
> 技术栈：前端 Vue3 + Vite（+ Vue Router / Pinia / Axios / animate.css）；后端 Express + better-sqlite3 + JWT + Multer + XLSX + bcryptjs；部署 Railway + GitHub Pages
> 代码仓库：`D:\github-staging\lottery-app`（项目名 lottery-app，根 package.json + client/ 前端子项目）

## 项目背景与目标
- 为安全产品二部&三部的文化活动提供现场抽奖能力，采用"扭蛋机/盲盒"视觉风格（半透明蓝色盲盒 + 粒子特效）。
- 受众：部门内部员工现场抽奖，需白名单资格管控 + 奖品库存管控 + 领奖信息回收。
- ⚠️ [待补充] 立项背景、需求方、首用活动场景与日期（源代码时间戳显示主体开发约 2026-05，README 图像素材生成于 2026-05-04）。

## 功能地图
### 用户端（client/src/views/LotteryPage.vue）
- 悬浮发光盲盒：半透明蓝色盲盒，棱角微光，上下浮动 + 旋转动画
- 星星粒子点缀（周围闪烁发光星点）+ 开盒粒子爆炸（蓝金炫光向四周扩散）
- 毛玻璃奖品卡片（PrizeCard.vue）：光晕边框，由虚变实的弹出动画
- 领奖信息表单：自定义字段，支持多种领取方式
- 白名单验证：非白名单用户点击后显示灰色提示

### 管理后台（client/src/views/AdminPage.vue，默认 admin / admin123）
- 数据看板：总库存 / 已抽数 / 剩余数 / 已抽人数 / 未抽人数 + 奖品维度表 + 中奖名单
- 资格管理：导入 Excel（姓名/工号/部门/中心）、手动添加删除、搜索筛选、重置状态（单人 / 批量）
- 奖品管理：添加编辑删除、图片上传（Multer）、库存管理
- 领奖信息：筛选查看、导出 Excel、标记领取状态
- 字段管理：所有前端文案与表单字段均可二次编辑（config 路由 + 后端持久化）

## 技术决策
- 前端 Vue3 Composition API + Pinia 状态 + Vue Router（/ 抽奖页、/admin 后台）
- 后端 Express + better-sqlite3（server/db/init.js 初始化）；JWT 认证 + bcryptjs 密码；Multer 文件上传；XLSX 处理 Excel 导入导出
- 防重复抽奖：同一工号只能抽一次；重置用户恢复对应库存
