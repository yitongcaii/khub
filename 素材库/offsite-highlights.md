## 二、专题：共创愿景墙（破冰 + 共识工具）

把个人对团队未来的想象，快速收敛成一面「看得见、能合影、可对照」的集体墙。思路参考 📌 医疗「我有美酒你有故事吗」使命愿景活动。

### 轻量版（破冰用，5–10 分钟）

  1. 准备物料：一面墙 + 便利贴 + 马克笔；或线上协作白板
  2. 抛锚问题：主持人只问一句——「如果用**一个词 / 一句话** 描述我们团队明年想成为的样子？」
  3. 个人写：每人匿名写 1–3 张便利贴
  4. 贴墙：鼓励边贴边看别人的
  5. 现场聚类：志愿者把相似便利贴归堆，主持人读出高频词
  6. 命名 + 合影：给整面墙起个主题名，全员合影

### 深度版（战略对齐，30 分钟）

  1. 搭三栏时间轴：墙上贴「现在 / 1 年后 / 3 年后」
  2. 分维度写：按「业务、团队氛围、个人成长」分组认领
  3. 世界咖啡轮转：每组写自己栏，再轮转补充 / 点赞
  4. 收敛命名：每栏提炼 1 句「我们共同的承诺」
  5. 高管呼应：把墙作为后面 GM 战略发言的「群众基础」
  6. 沉淀：拍照 + 转词云 / 录入智能表格，会后发全员

常见坑点：问题太宏大→冷场（务必给具体锚点）；只贴不收→变装饰（必须聚类+命名+呼应）；线上参与感弱（异地用协作白板同步）；高管不在场易失真（深度版建议和战略环节绑定）。

## 三、七大环节设计卡

#### 1\. 业务图景共享

定位：打破信息孤岛 ｜ 时长 40–60min ｜ 📌 安全产品一部&科恩 Offsite

  1. 按「产品/能力/支撑单元」分块，每块负责人讲
  2. 统一模板：2025 亮点 + 待提升 → 2026 方向 + 里程碑 → 对兄弟团队的需要
  3. 每人严格 8–10min
  4. 现场画「关联地图」

**产出** ：跨团队依赖 / 协同地图 ｜ **坑点** ：变述职→保留「对他人的需要」那页；时间失控→计时员举牌

#### 2\. 战略对齐

定位：回答「为什么打这场仗」 ｜ 时长 30–45min ｜ 🌿

  1. 高管 1 页讲「上层战略压到我们这层的 3 个必然」
  2. 分组讨论：哪些在主航道、哪些要调整
  3. 每组贴 3 张便利贴：**坚持的 / 要砍的 / 要新做的**
  4. 高管当场回应，形成「战略落点清单」

**产出** ：战略落点清单 ｜ **坑点** ：高层讲完就散→必须留「回应+清单」；别让战略沦为口号墙

#### 3\. 轻研讨

定位：用轻量方式深度碰撞真问题 ｜ 时长 45–60min ｜ 📌 云技服 Offsite

  1. 会前定 1 个好问题（如「AI 如何放大人的能力」）
  2. 世界咖啡：4–5 桌，每桌 6–8 人，15min/轮；换桌留 1 人当桌长
  3. 桌长汇总贴主墙
  4. 投票选 Top3 可落地动作 + 认领负责人

**产出** ：Top3 行动项 + 负责人 ｜ **坑点** ：问题太大→空谈；桌长机制不能省；严格控时

#### 4\. 总监 / 高管脱口秀

定位：轻松人设拉近距离 ｜ 时长 15–20min/人 ｜ 📌 云技服「总监脱口秀：AI 落地畅想」

  1. 选 1–2 位有表达欲的总监，给主题
  2. 脱稿 + 金句 + 自黑梗，配轻松 BGM 和梗图 PPT
  3. 台下用协作白板实时弹幕 / 举牌互动
  4. 收尾抛 1 个问题给下一环节

**产出** ：可传播的金句 / 短视频素材 ｜ **坑点** ：变念稿→必须脱稿+彩排；高管放不开→提前给「允许自黑」许可

#### 5\. 协作挑战赛

定位：在玩中暴露协作模式，强制跨团队混编 ｜ 时长 60–90min ｜ 🌿

  1. 随机混编，4–6 人/队
  2. 任务故意设「信息分散」，必须沟通才能解
  3. 设观察员记录「谁在串联、谁被忽略」
  4. 复盘：每人 1 句话讲协作

**产出** ：协作观察笔记 + 复盘共识 ｜ **坑点** ：变纯竞技→强调复盘非输赢；熟人抱团→强制混编

#### 6\. 主题跑步

定位：低门槛运动传递「长期主义 / 一起跑」 ｜ 时长 半天或打卡制 ｜ 📌 医疗「医群人一起跑」

  1. 定主题隐喻（如「安行四海」→海边跑）
  2. 设弹性距离（3 / 5 / 10km）
  3. 配速员带跑 + 中途补给 + 终点合影 + 完赛徽章
  4. 跑后小圈分享：「这一年我们像这场跑的哪一段」

**产出** ：合影 + 完赛物料 + 一句团队隐喻 ｜ **坑点** ：运动门槛→必须多距离；别变 KPI 打卡→强调「同行」非成绩

#### 7\. 承诺墙

定位：把共识变成可对照的承诺，收尾锚点 ｜ 时长 10–15min ｜ 🌿

  1. 每人 1 张卡片：「回到岗位后，我会做的**一件具体小事** 是___」
  2. 要求可验证（忌「努力 / 加油」）→ 示例「每周和跨团队同步 1 次」
  3. 贴墙 / 投承诺箱，拍照
  4. 可选：3 个月后回收对照，做「承诺兑现」回顾

**产出** ：一面承诺墙 + 可回溯的承诺清单 ｜ **坑点** ：写空话→给示例+要求具体；贴完就忘→设 3 个月回溯机制

## 四、主线串联建议

7 个环节可串成一条完整 Offsite 主线：

**图景共享 → 战略对齐 → 轻研讨（出动作）→ 脱口秀（松情绪）→ 挑战赛 / 跑步（强关系）→ 承诺墙（锁落地）**  
开场可叠加「共创愿景墙」作为破冰与结尾对照锚点。
