# 具身智能行业绩效管理框架

> 一键页：[具身智能行业绩效管理框架（GitHub Pages）](https://yitongcaii.github.io/activities-html/hr/embodied-pm-framework.html)
> 源文件：`D:\AI\workbuddy\2026-08-19-18-07-10\embodied-pm-framework.html`

一张可交互单页框架，讲具身智能行业怎么做绩效管理。四个模块：

1. **行业三大现实** — 长周期高不确定 / 强跨学科 / 软硬一体难归因
2. **按角色分桶指标**（可切换）— 算法·智能层 / 软件·系统层 / 硬件·结构·电控 / 产品·量产·项目，各列量化指标 + 评价方式
3. **落地四步流程** — 定层级目标 → 双轨评价 → 拉长窗口+里程碑发放 → 失败可记录
4. **三大坑点** — 互联网人效压具身团队 / 算法唯论文唯Demo / 忽视供应链制造角色

**核心结论**：研发周期长、跨学科、软硬难归因 → 必须分层分角色 + 双轨评价 + 拉长评价窗口，别用互联网 KPI 一刀切。
