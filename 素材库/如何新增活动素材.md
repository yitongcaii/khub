# 🛠 如何新增活动素材（SOP）

本库活动素材的两条新增路径，以及命名 / 链接规范。新建前先看这里。

## 路径 A（推荐）：HTML → GitHub Pages → MD
适用：需要在线交互动效的素材（Banner、Vol 玩法、Offsite 环节页等）。

1. 在 `D:\activities-html\` 下新建 / 修改对应的 `.html`
2. `git push` → 自动更新 GitHub Pages（线上地址：`https://yutttyi.github.io/activities-html/<文件名>.html`）
3. 在 Obsidian 按**同名**新建 `.md` 笔记（放在 `素材库/`）
4. 按以下 frontmatter 字段填写：
   - `title`：中文名
   - `tags`：对应分类（员工大会 / offsite / 创意实验室 / vol / banner）
   - `source`：线上 URL
5. 正文写文字摘要（完整动效留在线上，顶部用 🌐 链接指向）
6. 必须回链 `[[00-活动总览]]` 与 `[[index]]`

## 路径 B：纯 Obsidian 撰写
适用：纯文字 / 复盘 / 案例类笔记。

1. `Ctrl+N` 新建笔记
2. 手动添加以下 frontmatter 字段：
3. 写内容 + 加 `tags:` + 回链 `[[00-活动总览]]`
4. 图谱会自动按标签归类

## 命名规范
- 活动素材：`素材库/<英文名>.md`（与 GitHub Pages 文件名一致，便于对应）
- MOC / SOP / 索引：`00-` 前缀置顶
- 模板位置：`Templates/` 保留给可复用模板（当前未启用模板插件，直接填 frontmatter 即可）

## 链接规范（必做）
- 每条笔记都回链 `[[00-活动总览]]`（库内主索引）与 `[[index]]`（线上目录镜像）
- Vol 系列按 `🔗 上一期：[[volN-1]] ｜ 下一期：[[volN+1]]` 串成链
- 真实活动案例沉淀到 `案例库/`（用「案例卡模板」）
