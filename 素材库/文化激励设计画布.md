## 核心：激励 = 全面薪酬（从"人"出发，非工资奖金）
- 为何做：文化导向(行为) × 战略意图(结果)；失效本质=战略意图不清
- 激励谁：回归"人"（视人为人），非角色属性
- 四组平衡：统一vs个性 / 物质vs精神 / 固定vs浮动 / 短期vs长期
- 盖洛普 Q12（书中引）→ 年轻人"干得开心"当动力，可作活动效果验收表
- 时机：违背时机=白做（下行期硬做分享违背时机）
- 预判质疑：激励只决定能力重心偏移，不带来能力增长

## 套进 y 的文化活动/AI 文化运营
- 左书右你画布：统一框架+团队自定义 / 速赢奖金+即时认可 / 固定参与+浮动挑战 / 单次惊喜+长期勋章
- 文化活动定位=激活与连接，别承诺"激励改变业绩"
- 思维模型：第一性原理 / 系统平衡 / 预判质疑 / 时机杠杆
