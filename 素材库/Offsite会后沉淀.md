# Offsite 会后沉淀（知识库模块）

> 知识沉淀 · 成败 TIPS · 角色分工 · 典型 Rundown
> 完整可交互内容见源链接；本文为 Obsidian 内可搜索萃取版。

## 概述
一句话定位：Offsite = 让少数人把难事想透并达成共识（向内收）；员工大会 = 把信息和大情绪传给很多人（对外扩）。本模块只讲前者，是 Offsite 实操标准与沉淀资产。

## 一、定义
基于部门组织 / 业务定位与当前机遇 & 卡点，在抽离日常的场域里，把问题摊开、对齐未来方向、产出具体解法。核心特征：**小圈、深度、产出**——不是团建旅游，不是小型员工大会。

## 二、标准环节（see → align → act）
三段式逻辑自洽：看见全貌 → 对齐方向 → 碰撞出行动。

| 环节 | 作用 | 关键做法 |
|---|---|---|
| 1. 业务图景共享 | 打破信息孤岛（see） | 各单元讲「亮点+不足+对他人的需要」，现场画依赖/协同地图 |
| 2. 战略对齐 | 把方向吵清楚（align） | 上层方向翻译到本团队，形成「战略落点清单」（坚持/砍掉/新做） |
| 3. 研讨 | 深度碰撞出具体行动（act） | 世界咖啡轮转，投票选 Top3 可落地动作并认领 owner |

可选补充：开场建信任（破冰/共创愿景墙）；收口做承诺（承诺墙——每人写「回到岗位会做的一件具体小事」）。

## 三、目的与选型（一场只实现 1–2 个）
- **对齐类**：战略对齐（融合/变革）、战略解码、新 leader 上任
- **解决类**：方向/业务/协作卡点、提高组织效率、挖掘潜在问题
- **探索类**：共谈发展机遇、发现业务/合作机会

## 四、成败 TIPS
- **人要对**：有决策权/话语权的人在场（通常 10–40 人）；融合期两边关键人都必须到
- **场要 open**：开场立规则（保密/可 disagreement/发言机会均等）；姓名卡不写头衔；敏感场用专业引导
- **有前置（pre-work）**：会前 1–2 周发 pre-read / 小问卷，把「机遇&卡点」先同步
- **有产出**：研讨必须产出带 owner + 截止日的行动项
- **有跟进**：散场 48h 内发纪要；90 天回溯行动/承诺兑现

## 五、角色分工
| 角色 | 是谁 | 负责什么 |
|---|---|---|
| 业务 Leader | 团队负责人 | 内容 owner——定目标、定关键议题、当场拍板 |
| HRBP（你） | 你 | 场域设计 + 引导 + 跟进；退到幕后让对话发生 |
| Facilitator | 内部有引导力者 / 外部 | 带讨论、拉齐观点（敏感场建议外部） |
| PM / 统筹 | 你或行政 | 场地、物料、餐饮、行程 |
| 参与者 | 核心团队 | 真参与、出产出，不养旁观者 |

## 六、加分项
- **共创**：每个人都要参与发言 & 分享，不养旁观者
- **行动**：明确当下 & 未来的行为项，且真有人跟（对应 TIPS 4–5）

## 七、典型 Rundown
| 时间 | 环节 | 作用 |
|---|---|---|
| 09:00–09:30 | 开场：定目的 + 立规则 | 收心、立心理安全 |
| 09:30–10:30 | 业务图景共享 | 打破孤岛 |
| 10:30–12:00 | 战略对齐 | 共识落点 |
| 12:00–13:30 | 午餐 + 轻活动（不强竞技） | 充电 |
| 13:30–15:00 | 研讨（世界咖啡） | 出动作 |
| 15:00–15:15 | 休息 | — |
| 15:15–16:00 | 总监 / 高管脱口秀（可选） | 松情绪 |
| 16:00–17:00 | 协作挑战 / 主题跑步（可选） | 强关系 |
| 17:00–17:30 | 承诺墙 | 锁落地 |

重议题放上午；饭后安排轻互动；每 60–90 分钟休息。

## 八、常见翻车点（设计层）
- 为 Offsite 而 Offsite：无清晰目的，变成"花了钱聊了天啥也没变"
- HRBP 抢戏 / leader 念稿：没有真对话
- 强制 fun：尴尬破冰、强竞技，成年人反感，关系更远
- 只讨论不落地：出 10 条共识无 owner，三个月回原点
- 人不对 / 场不 open：关键人没来，或敏感场没人敢说

## 九、与员工大会的核心区别
| 维度 | 员工大会 | Offsite |
|---|---|---|
| 目的 | 传达 / 表彰 / 声量 | 对齐 / 融合 / 解决真问题 |
| 规模 | 大（全员） | 小（核心圈 10–40） |
| 形态 | 一对多讲 | 多对多共创 |
| HRBP 角色 | 执行统筹 | 设计 + 引导 |
| 产出 | 情绪 + 记忆 | 行动项 + 共识 |
| 价值点 | 当天 | 散场后 90 天 |

**组合打法**：先 Offsite 让核心圈对齐方向 → 再员工大会向全员广播成果。
