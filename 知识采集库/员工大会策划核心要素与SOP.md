## 摘要
中型科技公司（300-500人）年度员工大会的系统策划框架——从目标、主题、场地、时间到内容板块与策划步骤，可直接套用的 SOP 骨架。整合两篇 zbj 策划案例。

## 要点
1. **目标五维**：强化归属感 / 传递战略 / 表彰激励 / 释放压力 / 打造雇主品牌（对内对外传播）。
2. **主题设计公式**：科技感（契合业务）+ 人文关怀 + 未来感，与战略文化高度契合。例："智汇星辰·创享未来"（智汇=AI领域智慧碰撞，星辰=远大目标与员工闪光点）。
3. **场地三原则**：交通便利（1h车程+大巴往返，解决痛点）/ 环境区隔（近郊度假会议中心制造"特殊感"、放松感）/ 功能齐全（大宴会厅+分论坛会议室+住宿+休闲）。
4. **时间安排**：1天半——周五下午抵达破冰 + 周五晚核心盛典 + 周六上午战略分论坛/工作坊，不占周日。
5. **策划六步 SOP**：①立项&预算 → ②团队组建（市场牵头+HR/行政/IT+外部活动公司）→ ③选址签约 → ④主题&VI深化（主KV/流程脚本）→ ⑤嘉宾邀请（H5电子函专人跟进）→ ⑥物料制作。
6. **内容板块**：破冰（创意签到/互动体验区/团队挑战）+ 核心盛典（CEO演讲/颁奖/节目）+ 分论坛（技术前沿/业务方向/文化讨论）。
7. **创意亮点（500人案例）**：沉浸式"时光隧道"回顾走廊、人脸识别生成专属电子胸牌、全息投影"未来使者"引出颁奖、激光舞/无人机编队、高管以"船长日志"形式发年度报告。

## 执行提示层（具体怎么做）
- **主题命名怎么做**：3 公式——①具体动词+业务关键词 ②数字+情绪名词 ③反问句+公司名；对仗式结构增强记忆点；提前 60–90 天定调，给物料与宣发留期。
- **时光隧道怎么做**：照片墙 + 投影时间轴 + 感应灯带做走道；互动投影设备可租赁（如硕莹文化沉浸式投影 ¥4500 起）。
- **人脸电子胸牌怎么做**：人脸采集 → AI 生成专属模板 → 现场打印/电子胸牌；创意签到设备租赁（光绘签到 ¥2000 / AI 拍照互动 ¥2000–8500）。
- **全息"未来使者"怎么做**：佩珀尔幻象 / 全息箱（180/270/360°），租赁 ¥12800/套起，供应商颢影 / 影炫。
- **激光舞·无人机怎么做**：无人机 200 架≈5–8 万、2000 架≈50–80 万；选一站式供应商（空域申请+执行+售后），交付周期 7–15 天，参考世纪成美 / 高巨创新。
- **船长日志年报怎么做**：以"船长视角"第一人称重写年报文案 + 配 VCR 包装，属文案形式创新，无需额外设备。
