# data-report-guard · 防错出报告 Skill

> 出数据报告前自动卡死「源错/算错/口径换/编」四大雷区的可复用 skill。

## 一句话
按"防错模板"出报告时，强制走 6 招：锁源 → 写死口径 → 复述确认 → 埋基准数 → 内嵌溯源+占位 → 出报告（含自查段）。

## 怎么用
- 触发词：**「按防错模板出报告 / 出数据 / 做分析(防错)」** —— 仅显式触发，普通"出报告"不跑
- 安装位：`~/.workbuddy/skills/data-report-guard/`（user 级，跨项目）
- 边界：不自动触发 / 不填估算值 / 不改源 / 不推Pages不发企微 / 源找不到必反问 / 单次单任务
