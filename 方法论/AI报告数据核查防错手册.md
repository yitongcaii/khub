# AI 报告数据核查 · 防错手册

一句话：agent 出的分析报告，怎么判断数据错没错、怎么从源头防错。Bento 卡片墙 HTML，可直接查、可复制指令模板，关键占位字段可点开改并本地保存。

## 核心要点
- **判断 4 维度**：源对不对 / 算对没 / 口径守没守 / 有没有编
- **30 秒验错 3 招**：抽一个你心里有数的数 / 警惕太整齐的数字 / 看口径说明在不在
- **防错 6 招**：锁源 / 写死口径 / 先确认再干 / 埋基准数 / 内嵌溯源 / 占位防编
- 含「让 agent 自查话术」+「防错指令模板」两个可复制按钮
