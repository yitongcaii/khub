## 四类机位
1. **角度**：平视 / 仰拍(显威) / 俯拍(显渺小) / 顶拍鸟瞰 / 荷兰角(失衡)
2. **景别**：大远景 / 全景 / 中景 / 近景 / 特写 / 大特写
3. **方向**：正面 / 侧面(1/5蒙太奇) / 斜侧3-4 / 背面 / 过肩(双人,AI高风险)
4. **运动**：推近(全景→特写·聚焦/压迫) / 拉远(特写→全景·释然/格局,AI易漂优先后期) / 横移 / 手持微晃 / 环绕(高风险) / 摇 / 升降(高风险) / 跟拍

## AI 翻车高发
- 大幅环绕 / 升降 → 易晕易漂，拆小幅或后期
- 过肩双人 → 互穿、脸漂，优先单主体近景
- 特写/大特写 → 放大手部畸形/歪眼，负面词补全 + 锐利对焦

## 组合建议
- 战斗：仰拍全景→近景特写→低角度跟拍
- 四季蒙太奇：固定同「侧面1/5」机位只换天/地
- 收尾：中景平视→俯瞰城市定格
