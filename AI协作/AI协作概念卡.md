## 六个词速览（人话版）
| 词 | 像啥 | 一句话 |
|---|---|---|
| Prompt | 你跟实习生说的一次话 | 临时提要求，说完就完 |
| Skill | 贴桌上的标准作业卡 | 存好的可复用流程，下次直接叫 |
| MCP | 给 AI 开的外部插头 | 插上才能碰公司系统（企微/腾讯会议…） |
| CLI | 打字让电脑跑的黑框 | 不点鼠标，粘贴命令回车 |
| API | 软件之间隔窗点单 | 两程序互相传话的通用通道（地基） |
| Automation | 定时自动跑 | 你定"每天10点做XX"，电脑自己干 |

## 关键关系（易混点）
- **API 是地基（大类），MCP 是盖在 API 之上的 AI 专用标准插头**——不是 API 包含 MCP，是 MCP 调用 API。
- **prompt 是零件，skill 是装好零件的机器**：会做第二遍就升级成 skill。
- **automation = 什么时候跑**，跑的内容常是某个 skill / prompt。
