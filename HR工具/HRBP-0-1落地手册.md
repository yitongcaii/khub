## 一句话
0-1 核心心法：不先搭大体系，先找最小样本跑通，再系统化。两个模块都按"定位→跑通→系统化→指标闭环"推进。

## 模块一：雇主品牌
- 本质：对内让员工愿留、对外让候选人愿来；核心是 EVP（雇主价值主张）。
- EVP 五维：薪酬福利 / 成长发展 / 团队氛围 / 工作意义 / 稳定性（云技服适配卖点已标定）。
- 四阶段 0-1：定位(W1-2) → 对内体验(W2-4) → 对外内容(W4+) → 量化迭代(M2-3)。
- 指标：Offer接受率≥85%、内推占比目标≥30%、eNPS≥30、面试NPS≥8、单hire成本↓。
- 避坑：只对外不对内 / EVP假大空 / 内容断更 / 只看曝光不看转化。

## 模块二：新员工入职培训
- 框架：30-60-90 成长闭环 + 70-20-10（实战70/导师20/课程10）。
- 四阶段 0-1：搭骨架(W1-2) → 跑首批(W2-6) → 系统化(M2-3, 飞书多维表格) → 指标闭环(M3+)。
- 系统化承载：飞书多维表格《新人成长地图表》（字段+节点自动提醒+仪表盘），思路同薪资看板。
- 指标：入职NPS≥8、试用期通过率≥95%、3月留存≥90%。
- 避坑：只讲课不实战 / mentor无激励 / 6个月才反馈 / 无目标对齐。

## 通用 0-1 打法
小样本试 → 借现有资产(英语角/黑客松/AI文化) → 一张表管 → 指标前置。
