## 一句话
一张表承载「原始数据 → 自动校验 → 异常标红 → 仪表盘预警」，让每次核算从"重算一遍"变成"跑一遍看板"。

## 核心构成
- **主表《薪资核算明细》**：每行一个人·一个月，含固定/浮动/扣款/校验字段。
- **仪表盘《核查驾驶舱》**：总包、部门分布、异常分布、趋势。
- **视图**：全部数据 / 异常清单（筛选异常）/ 按部门看板。
- **高级权限**：HRBP 可编辑、部门负责人只看本部门、财务看汇总不可改。

## 关键公式（粘贴即用）
- 应发 = 基本+岗位+绩效+津贴+奖金+加班费−缺勤扣款
- 实发 = 应发−社保个人−公积金个人−个税−其他扣款
- 环比波动% = IF(上月实发>0,(实发−上月实发)/上月实发,0)
- 校验结果 = 不平则标"应发合计不平/实发不平"，否则"通过"

## 条件格式（命中即标色）
漏发(实发=0)、波动超±20%、个税=0且应发>1万(漏税)、校验≠通过、离职却计全月、社保基数滞后、银行卡缺失、同岗倒挂 → 红/黄。

## 落地节奏
T-5 数据锁定 → T-3 核算自查 → T-2 部门确认 → T-1 HRBP+财务复核 → T 发薪。

## 用法
照 HTML 里的字段清单建列、粘贴公式、配条件格式与仪表盘即可。重点从"重算"转为"查异常"。
