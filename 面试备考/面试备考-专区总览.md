# 面试备考专区总览 · 作战地图

- 聚合页（四件套入口）：https://yitongcaii.github.io/activities-html/resume/interview-hub.html

## 四件套（按使用顺序）
1. [[面试备考-面试题库作战卡]] — 背答案（42 问答，全维度无省略）
2. [[面试备考-面试方法论卡]] — 打法（40 战术卡：战略/战术/细节/轮次/面试官/心态/跟进/矩阵）
3. [[面试备考-补充包]] — 血肉（44 卡：数字台账/STAR库/薪资剧本/逐字稿/作品包/观点库/战役日志）
4. 作品包（本地文件夹，非网页）— 证据：看板截图/答辩PRD/文化一页纸/知识分层/AI漫剧分镜

## 备考节奏
- **面前列**：方法论卡定策略 → 补充包回填数字 + 写逐字稿 + 备作品
- **面中**：题库卡照答，弱点预案兜深挖
- **面后**：填战役日志复盘，反哺题库与数字台账
- **模拟面试**：让 AI 当面试官演练，把"背"变"说"（见对话，可随时发起）
