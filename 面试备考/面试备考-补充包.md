## 11 分类（44 张卡，可点开编辑，浏览器本地保存）
- **数字台账**：唯一真相源，所有对外材料取数，必须一致（答辩/看板/AI文化/英语角/文化周/总量词/求职参数）
- **弱点预案**：3 个真实弱点被深挖的具体接法（多线做浅 / 技术边界估不足 / 采纳率无数据）
- **STAR库**：10 个完整故事，能扛三连问（答辩/看板/布道师/知识过滤/文化周/英语角/推动leader/H2/审批闸门/多线兜底）
- **薪资剧本**：终面必用，目前零覆盖（问范围/给区间/被压价/低于期望/现薪资）
- **电梯演讲**：30秒 / 1分钟 / 3分钟 三版
- **逐字稿**：自我介绍 / 核心竞争力 / 动机 三篇写定
- **目标公司**：每投一家复制填一张（业务判断/能力对位/反向提问定制）
- **战役日志**：每次面完复盘模板 + 复盘维度
- **观点库**：5 篇可发社交（AI+HR/组织效能/文化/预测PA/克制自动化）
- **作品包**：清单 + 30秒讲解词（看板/PRD/文化一页纸/知识分层/AI漫剧）
- **档案优化**：LinkedIn/脉脉 优化清单（外部动作，你执行）

## 使用
红/黄卡 = 待填真实数字，点开即填，浏览器 localStorage 自动保存。面试前把【待补】回填，且与简历数字一致。
