## 一、岗位一句话定位
HRD 的「内部项目经理 + 协同中枢」。把散在各 HR 模块的专业能力，用项目和流程串成部门级结果。**不是对外业务 BP，是内部中台型 BP。**

## 二、JD 拆解
- 5 条核心职责：跨模块协同 / 专项跟进落地 / 数据支持 HRD 决策 / HR 部门团队建设 / 公司级 HR 项目全生命周期
- 硬要求：本科 + 2–4 年；优先 HRBP / 项目 / 模块协同经验；熟悉全模块 + 1–2 核心模块扎实；精通劳动法规；自驱 / 逻辑 / 数据 / 协同 / 闭环

## 四、30 秒定位语
我是蔡依彤，2 年多 HR 经验，核心三块：**流程产品化**（腾讯把新人转正从人工跟催做成系统自动推进）、**专项落地**（公司级激励评选 / 文化活动全流程）、**资源整合**（联志 0-1 搭内推体系、独立交付 20+ 岗位、90% 留存）。这个岗要的是能把 HR 专项从想法推到结果的人，这是我一直在干的事。

## 五、三个 STAR 逐字稿
### 1. 新人转正自动化流程（对齐：专项跟进 / 流程优化 / 数据支持）
- **S**：腾讯新人转正原靠人工跟催，BP 每月手动核对名单、催材料、汇总，易漏易晚。
- **T**：0-1 把流程自动化，系统代替人工，沉淀可复用规范。
- **A**：① 梳理卡点（谁审 / 审啥 / 何时触发）；② 拉 HRIS + BP 定规则配自动触发节点提醒；③ 上线数据校验 + 沉淀 ISOP 台账。
- **R**：人工跟催 → 系统自动推进，减少手动统计，避免节点遗漏。

### 2. 激励评选全流程跟进（对齐：跨模块协同 / 专项落地 / 闭环）
- **S**：公司级激励评选跨多模块，信息分散、进度不透明。
- **T**：支持 BP 做全流程跟进，公平 + 进度可控 + 结果及时落地。
- **A**：① 统一申报入口与材料标准；② 搭评审进度看板（BP / 评委 / 财务实时可见）；③ 跟奖金分配与宣发，闭环。
- **R**：评选按期完成，申报-评审-发奖-宣发闭环跑通。

### 3. 联志 0-1 内推体系 + 招聘交付（对齐：资源整合 / 项目全生命周期 / 闭环）
- **S**：联志无系统内推，靠猎头成本高。
- **T**：0-1 推行内推制度，降成本提占比。
- **A**：调研业务需求 → 设计年度宣导 + 奖品制度 → 海报 / 推文 / 会议推广 → 建内推台账定期公示。
- **R**：独立交付 20+ 岗位（总留存 90%）；内推 20+ 人入职，降招聘成本。

## 六、防守素材（应对"核心模块扎实 / 法规"）
乐心独立负责深圳 300 人 SSC（入离职 / EHR / 考勤 / 档案）+ 独立办外籍员工在华工作许可；设计部门长文化调研问卷回收 53% 并做价值观拆解。说明 SSC 模块扎实、法规合规经实战、具备数据支持能力。

## 七、短板话术
- **非科班**：2年+ 全职实习都在 HR 一线，模块切换 + 3 次 0-1 搭建，比单模块出身更适"串模块"岗。
- **无电商全职**：安芯易实习做全流程招聘 + 雇主品牌，技术团队 1000+ 人活动经验，快节奏环境能适应。
- **年限 2 年**：密度高（4 段模块 + 3 次 0-1），岗位下限 2 年，核心看落地闭环。

## 九、数字防御
- **90% 留存**：交付入职者在约定考察期（如 6 个月）内仍在职比例，20+ 岗位样本。
- **53% 回收率**：面向部门长调研，管理层回收本难，53% 够做价值观拆解且分层分析出结论。
- **1000+ 覆盖**：活动触达人数，独立负责方案-物料-执行-复盘全流程。
- **300 人 SSC**：独立负责分公司 300 人全盘事务，非带 300 人团队。

## 十、HR中台 vs 传统HRBP
- **BP** = 把业务的话翻成 HR 的事（对外）；**中台** = 把 HR 的事做成标准工具（对内）。
- 面试别说自己"业务伙伴 / 政委"，要说"把 HR 专项产品化、流程化、能复用"。

## 十一、专项清单 + 困难解法（核心增量）
**专项四类**：体系类（薪酬 / 绩效 / 人才 / OD）、文化类（价值观 / 活动 / 荣誉）、流程类（HR 流程产品化）、团队类（HR 部门自身建设）。

**共性困难 Top 5 + 解法**：
1. 跨模块推不动 → 看板 + 拆任务 + 定期同步（ISOP 台账 / 评审看板）
2. 数据底子弱 → 小范围试点 / 埋点，最小数据启动（文化调研 53% 先跑）
3. Owner 模糊 → 单一主责人 RACI
4. 不买账 → 前期访谈 + 痛点切入 + 给甜头（内推奖品）
5. 后期烂尾 → 里程碑 + 自动提醒 + 必做复盘（PDCA）

**通用落地框架**：设计（诊断→定目标→出方案）→ 落地（拆任务→定主责→建看板/数据）→ 复盘（看效果→沉淀资产）。
