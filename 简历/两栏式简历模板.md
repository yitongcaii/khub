# 两栏式简历模板（针对「短且杂」经历）

> 配套能力簇分组版见 [[能力簇分组简历模板]]。两版都治「每段短、每段内容不同」的痛点，只是组织逻辑不同。

## 在线链接
- 两栏式（本版）：https://yitongcaii.github.io/activities-html/resume/two-column.html
- 能力簇分组版：https://yitongcaii.github.io/activities-html/resume/

## 设计思路（为什么治你的痛点）
- **左栏立人设**：核心能力矩阵(星级进度条) + 关键数据大字报 + 技能标签。短经历不空洞，因为人设已先立住。
- **右栏填细节**：紧凑时间线，每段经历作为节点，配 CAR 三段式 + 能力胶囊标签。不同内容翻译成可归类标签。
- 左栏已把「你是谁」讲清，右栏短经历不再显单薄。

## 排版结构
头部(姓名/职位/联系/一句话主线) → 左栏(能力矩阵+关键数据+标签) / 右栏(时间线经历卡) → 署名页脚。

## 用法
- 单文件 HTML，所有字段 `contenteditable`，点进去直接改；示例文案标「✎ 示例·替换」。
- 紫青双色 Bento 风，含 `@media print` 可打印 A4；窄屏自动转上下栏。
