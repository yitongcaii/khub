# 面试第一性原理话术备忘

> 来源:2026-09-02 与小柚对练。2026-09-02 更新:所有话术**显式标注两大原理**,不再暗用。
> 配套简历:综合版 https://yitongcaii.github.io/activities-html/resume/resume-cai.html ｜ 画报版 https://yitongcaii.github.io/activities-html/resume/resume-cai-poster.html

## 🧱🔺 两大原理速记卡(面试前 30 秒扫一眼)
- **🧱 第一性原理**:把事拆到不能再拆的底层事实,从那重新想,不抄"向来如此"、不堆表面做法。话术里 = 从"我发现…本质是"起头。
- **🔺 金字塔原理**:结论先行;以上统下;归类分组;逻辑递进(先抛核心观点,再自上而下展开论据)。话术里 = 开场先抛成果/核心判断,不铺垫背景。

## 通用打法(四步,已标原理)
1. 🧱 **准备**:把 JD 拆到底 → 这岗到底在救什么火(回到真问题,不抄岗位字面)
2. 🔺 **自我介绍**:结论先行,从对方痛点反推 + 真实证据(先说"我解决过和你一样的坑",不列"我多优秀")
3. 🧱+🔺 **行为题**:🔺 先给结论(底层问题一句话),🧱 从"我发现…本质是"起头展开三层(问题→做法→结果)
4. 🧱 **反问**:问本质(前任为何走 / 90 天最关键指标)

## ⚠️ 红线(所有条通用)
- 数字一律 `__` 占位,定稿前不填虚数
- 参与度层级严格对应:主导 / 负责一块 / 执行落地 / 参与讨论
- 技术实现别说"我开发了",说"主导设计 + 落地推动,技术实现【__】"

## 经历1 · 腾讯(派遣)0-1 新人转正自动化流程
**🧱 第一性原理拆解**:表面"会用工具搭流程" → 真问题:新人转正全靠 HR 人工跟催,几十节点易漏、体验差、BP 被琐事淹。公司要的是「最小人力维持运转 + 新人快速融入」。证明你 = 把模糊痛点变可落地系统方案(流程产品化),且 0-1 从零搭。

**版A 自我介绍钩子**
> 我最近一份工作最有成就感的是——把一个全靠人盯人的流程"做没了"。新人转正原来 HR 要挨个跟催、容易漏,我把它从 0 到 1 改成了系统自动推进。这背后是我习惯先想"这事本质要解决什么",再用工具把它干掉,而不是硬扛。
🔺 金字塔:开场直接抛核心成果("做没了 / 0 到 1 改系统自动推进"),不铺垫公司背景。

**版B 行为题**
> 1. 底层问题:我发现新人转正卡在人工跟催——HR 要记几十节点、易漏、新人感受差。我回到本质问:这事儿到底要解决啥?是"在正确时间提醒正确的人做正确动作"。那它本质是**信息流的自动触发**,不是 HR 的记忆力。
> 2. 做法:拆成三步——触发条件(转正日期)、责任人、提醒动作,用【工具/系统名】搭自动流转,人工只兜底异常。
> 3. 结果:HR 跟催工时从【__】降到近 0,漏提醒【__】例,覆盖【__】名新人/年。
🔺 金字塔:先给结论(底层问题一句话),再三层自上而下。
🧱 第一性原理:从"我发现…本质是"起头,拒绝"领导让我做"的表层叙事。

**版C 防守**
> "系统你开发的?" → 按四级口径:"我**主导**从诊断到落地全过程,技术实现【和 XX 团队 / 低代码配置】",别说"我开发了"。
> "覆盖多少人?" → __占位:"覆盖部门【__】人规模,具体核实后给"。
> "为啥不用现成 SaaS?" → 🧱 第一性原理反杀:"现成工具贵且要改我们流程;真要的是轻量触发,自搭更贴合"。
红线:对应**主导**层级;若只参与配置,下调。

## 经历2 · 联志工业 0-1 内推制度(20+ 内推入职)
**🧱 第一性原理拆解**:表面"搞了内推" → 真问题:外部渠道(猎头/外包)贵且慢;内推真便宜因"员工推荐的人错配率低" = 信任背书,不是省钱噱头。证明你 = 从 0 建制度(非执行既有)+ 用运营驱动行为改变。

**版A 自我介绍钩子**
> 我上一份把公司内推从 0 做起来了——之前没这渠道,我建了制度 + 社群 + 奖品机制,跑出 20+ 内推入职,招聘成本直接降下来。我习惯先把"为啥要做"想透,再搭能自己转的机制。
🔺 金字塔:开场抛核心成果("从 0 做起来 / 20+ 入职 / 成本降"),不铺垫部门背景。

**版B 行为题**
> 1. 底层问题:招聘全靠外部渠道,贵且慢。我回到本质:内推真正便宜是因"员工愿意推荐的人,错配率低"——这是信任背书,不是省钱噱头。
> 2. 做法:从 0 定内推规则(谁能推 / 奖多少 / 怎么发)、搭内推社群、做年度宣导 + 奖品阶梯,把"偶然推荐"变"持续动作"。
> 3. 结果:跑出 20+ 内推入职,占【__】% 招聘量,单岗成本降【__】。
🔺 金字塔:先结论后三层。
🧱 第一性原理:从"贵且慢"拆到"信任背书"这一底层事实,不堆"我发了好多推文"。

**版C 防守**
> "内推你一人推的?" → "我主导搭建运营,业务 leader 配合发声,是跨部门活"(别独占也别缩成帮忙)。
> "20+ 留存如何?" → __占位:"和社招留存对齐,具体数字【__】"。
红线:"0-1 推行"对应主导 / 负责一块;若只写制度文档,下调层级。

## 经历3 · 腾讯 积分 + 抽奖游戏化平台
**🧱 第一性原理拆解**:表面"做了积分抽奖" → 真问题:活动参与低,员工觉"又来搞形式";本质是用游戏化机制(即时反馈 / 随机奖励)撬动动机,把"要我参加"变"我要参加"。证明你 = 懂行为设计 / 运营杠杆,能把文化落地做成产品。

**版A 自我介绍钩子**
> 我做文化活动最不信"拉人头凑数"。在腾讯我搭了积分 + 抽奖两个小平台,用游戏化让技术团队主动来参与——覆盖 1000+ 人。我底层想的是"人为什么愿意动",不是"活动多热闹"。
🔺 金字塔:开场抛反共识判断("最不信拉人头")+ 成果(主动参与 / 1000+),抓耳。

**版B 行为题**
> 1. 底层问题:活动参与低,硬推没人理。本质问题:员工缺"动一下就有反馈"的钩子。游戏化(积分即时到账 + 抽奖随机奖)正好补这个。
> 2. 做法:搭积分平台(行为→积分→可兑)+ 抽奖平台(随机奖制造期待),把学习 / 大会 / 日常动作都接进去。
> 3. 结果:覆盖 1000+ 人技术团队,参与率【__】→【__】,积分发【__】。
🔺 金字塔:先结论后三层。
🧱 第一性原理:从"人为啥不动"这一底层动机拆起,不堆"我办了多少场活动"。

**版C 防守**
> "平台你开发的?" → "我主导设计 + 落地推动,技术实现【__】",别说开发。
> "流于形式?" → 🧱 第一性原理反杀:"我盯的是参与后的行为改变(如学习完成率),不是抽奖热闹。形式只是入口"。
红线:参与率数字 __ 占位;技术实现按实际层级说。

## 经历4 · 乐心医疗 300 人全盘 SSC
**🧱 第一性原理拆解**:表面"管 300 人入离调转" → 真问题:分公司事务杂易错 + 涉外合规雷;本质是"高频动作标准化 + 系统兜底"。证明你 = 能扛全盘、懂系统配置、合规敏感(涉外)。

**版A 自我介绍钩子**
> 我在乐心独立扛过深圳分公司 300 人全盘 SSC——入离调转、EHR、考勤档案全自己来,还办了外籍员工工作许可。我底层做法是"把重复事系统化",让 300 人盘子不出错。
🔺 金字塔:开场抛"独立扛 300 人全盘"这一核心判断 + 差异化亮点(涉外许可),不铺垫公司规模。

**版B 行为题**
> 1. 底层问题:300 人事务靠人记必错,且外籍用工有合规雷。本质是"高频动作标准化 + 系统兜底"。
> 2. 做法:独立跑全盘入离调转,多次优化 EHR 配置被采纳,办《在华工作许可证》走通涉外流程。
> 3. 结果:300 人盘子 0 重大差错,系统优化建议【__】条被采纳,外籍许可【__】例。
🔺 金字塔:先结论后三层。
🧱 第一性原理:从"人为啥会错 / 合规雷在哪"拆起,不堆"我每天多忙"。

**版C 防守**
> "300 人你一人?" → "我是分公司 SSC 主责,跨部门对接薪酬 / IT,不是单打"(真实)。
> "EHR 优化提了几条?" → __占位。
红线:"独立负责"= 主责,但跨部门协作讲清,别缩成执行也别夸成一人扛全公司。
